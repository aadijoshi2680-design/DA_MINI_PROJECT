# SkyGraph Dashboard

A 3-page interactive airline network analytics dashboard for Neo4j OpenFlights data.

## Features
- **Home**: Real-time KPI counters, hero world map with PageRank nodes, top hubs and airlines.
- **Analytics**: 14 deep-dive ECharts visualisations covering centrality, reach, communities, and route metrics.
- **Route Explorer**: Client-side BFS and Dijkstra graph algorithms with animated flight paths.
- **UI Kit**: Accessible component system with dark theme control room aesthetic.

## Running Locally
```bash
cd skygraph-dashboard
npm install
npm run dev
```
